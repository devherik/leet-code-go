# LeetCode Go Practice

This repository contains my personal solutions to various LeetCode problems. The primary goal of this project is to improve problem-solving logic and master the Go programming language.

## Purpose

- **Logic Improvement:** Developing a structured approach to solving algorithmic challenges.
- **Go Proficiency:** Implementing idiomatic Go solutions, focusing on performance, memory usage, and clean code.

## Repository Structure

The files are named after their respective LeetCode problem numbers (e.g., `01.go` for Two Sum).

- `01.go` - Two Sum
- `02.go` - Add Two Numbers
- `03.go` - Longest Substring Without Repeating Characters
- `04.go` - Median of Two Sorted Arrays
- `49.go` - Group Anagrams

## How to Run

To run any of the Go solution files, make sure you have Go installed, then use:

```bash
go run <filename>.go
```
